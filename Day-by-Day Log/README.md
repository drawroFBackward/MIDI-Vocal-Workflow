# Day-by-Day Log

One-page records of study days in the MIDI Vocal Workflow project. The logs start with **Day 7**; Days 1–6 are intentionally not backfilled.

## File naming

- `Day-07.md`, `Day-08.md`, etc., one file per completed study day.
- A study day need not equal a calendar day. Use the actual date within each document.
- Each draft is reviewed by the user before being committed.

## One-page template

```markdown
# Day NN — [Short objective]

**Date:** YYYY-MM-DD (JST)  
**Status:** Draft — pending approval

## Objective
[What the day aimed to accomplish]

## Work completed
[Concise, concrete implementation and learning steps]

## Evidence
[Relevant commits, tests run, outputs and limitations]

## Concepts, challenges and corrections
[Learning, failures and how they were resolved]

## Important decisions and reasons
**<u>Decision — [what was chosen]</u>**  
**Why:** [Reasoning and alternatives considered]

## Next steps
[Concrete next actions]
```

Weekly learning reviews and comprehensive eight-calendar-week milestone summaries live in `docs/ProjectLog.md`, with links to corresponding daily logs as appropriate. Major decisions are recorded in the master decision register, in bold and underline with their rationale.
